# Glammed By Gabby

Website for **Glammed By Gabby** — licensed esthetician studio (lashes, brows, waxing) at 320 Broadway Blvd, Unit C, Reno NV.

Static site (HTML/CSS/JS), deploys on Vercel with no build step.

## Pages
- `index.html` — hero video, searchable service menu, Lash Finder, before/after sliders, gallery + lightbox, reels, reviews, studio & live hours, aftercare, contact/appointment form
- `about.html` — Meet Gabby bios page (bio copy marked `EDIT` for updates)

## Quick edits
- **Booking link** — change `CONFIG.BOOK_URL` at the top of `assets/js/main.js`; every Book button uses it (swap for Gabby's personal link or Square later).
- **Contact form** — posts to FormSubmit → `glammed.by.gabby07@gmail.com`. The first submission sends Gabby a one-time activation email; confirm it and messages start arriving.
- **Photos / videos** — `assets/img`, `assets/video`.
